# Ud2. AO – Plantilles administratives (LibreOffice)

Sis plantilles de documents administratius en format **.odt** (LibreOffice Writer).

## Carpeta `Ubuntu/Plantilles-administratives`

| Fitxer | Tipus de document |
|--------|-------------------|
| `1_Anunci_LibreOffice.odt` | Anunci de matriculació a les Escoles Municipals de Maó (ceràmica, música, dibuix) |
| `2_Carta_LibreOffice.odt` | Carta de l'IES Joan Ramis i Ramis sol·licitant 2 multifuncions a Xerox de Menorca |
| `3_Certificat_LibreOffice.odt` | Certificat d'estudis de 1r SMX |
| `4_Circular_LibreOffice.odt` | Circular del Servei de Recaptació sobre termini de pagament de l'IBI |
| `5_Citació_LibreOffice.odt` | Citació d'Hisenda per signar document del Model 061 |
| `6_Contracte_LibreOffice.odt` | Contracte de compravenda d'habitatge |

## Com utilitzar-les

1. Descarrega els fitxers `.odt`.
2. Obre'ls amb **LibreOffice Writer**.
3. Personalitza les dades variables (noms, dates, DNI, etc.).
4. Utilitza les eines d'ortografia de LibreOffice si cal.

Documents didàctics: completar els camps entre claudàtors i verificar les dades abans d'utilitzar-los. El certificat, la citació i el contracte no tenen validesa oficial o jurídica.
