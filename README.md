# Ud2. AO – Plantilles administratives (LibreOffice)

Sis plantilles de documents administratius en format **.fodt** (OpenDocument Flat XML, editable amb LibreOffice Writer).

## Carpeta `Plantilles-administratives`

| Fitxer | Tipus de document |
|--------|-------------------|
| `1_Anunci_LibreOffice.fodt` | Anunci de matriculació a les Escoles Municipals de Maó (ceràmica, música, dibuix) |
| `2_Carta_LibreOffice.fodt` | Carta de l'IES Joan Ramis i Ramis sol·licitant 2 multifuncions a Xerox de Menorca |
| `3_Certificat_LibreOffice.fodt` | Certificat d'estudis de 1r SMX |
| `4_Circular_LibreOffice.fodt` | Circular del Servei de Recaptació sobre termini de pagament de l'IBI |
| `5_Citació_LibreOffice.fodt` | Citació d'Hisenda per signar document del Model 061 |
| `6_Contracte_LibreOffice.fodt` | Contracte de compravenda d'habitatge |

## Com utilitzar-les

1. Descarrega els fitxers `.fodt`.
2. Obre'ls amb **LibreOffice Writer**.
3. Personalitza les dades variables (noms, dates, DNI, etc.).
4. Desa com a `.odt` si vols el format binari estàndard.

Documents didàctics: completar els camps entre claudàtors i verificar les dades abans d'utilitzar-los. El certificat, la citació i el contracte no tenen validesa oficial o jurídica.
