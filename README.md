# Plantilles administratives – LibreOffice Writer

Sis models editables en català en format ODT: anunci, carta comercial, certificat, circular, citació i contracte de compravenda. Consulteu la carpeta `plantilles/`.

Documents didàctics: completar els camps entre claudàtors i verificar les dades abans d'utilitzar-los. El certificat, la citació i el contracte no tenen validesa oficial o jurídica.
